# 🌲 快乐斗兽棋 (Jungle Chess / Doushouqi) 🦁🐭

> 一款基于 SwiftUI 精心打造的现代化经典单机益智斗兽棋游戏，内置未来 3 步战术深度推演、三大难度智能 AI、神兽绝技与精美 3D 视觉体验。

---

## 🌟 核心特色 (Key Features)

* **🧠 三大难度智能引擎 (Multi-Ply AI Engine)**:
  * 🌱 **轻松入门**: 适合新手与儿童，生动活泼，轻松上手；
  * ⚔️ **势均力敌**: 走一步看三步，攻守兼备，平衡对弈；
  * 👑 **兽王争霸**: 4-Ply Minimax 深度推演，掌控小河制空权，互保战阵，极具挑战性！
* **🔮 3步战术深度推演 (Tactical Foresight Advice)**:
  * 实时分析走法是 `👑 无损斩杀` 还是 `⚡️ 战略兑子 (+净赚战力)`；
  * 己方受威胁棋子拉响红色警报，智能引导老鼠遁入水中避险；
  * 独创水中猎鼠清障战术，解除河道封锁让猛虎雄狮飞跃小河！
* **⚡️ 独创神兽绝技 (Superpower Skills)**:
  * 🛡️ **神兽天降**: 瞬间召回最强主力空降大本营咽喉要道，诛灭偷家敌军；
  * 🔥 **狂暴猎杀**: 2回合内全员越级猎杀，以弱胜强，打破常规！
* **👥 多种对战模式**:
  * 支持 **人机对战** 与 **单机双人同屏对战**；
* **🍃 纯净绿色**:
  * 100% 离线单机运行，零个人数据收集，零广告弹窗，安全省心。

## 🦁 斗兽棋规则与食物链 (Rules & Hierarchy)

```text
象 (950) ＞ 狮 (850) ＞ 虎 (720) ＞ 豹 (500) ＞ 狼 (380) ＞ 狗 (280) ＞ 猫 (200) ＞ 鼠 (320)
```

1. **生克克制**: `🐭 鼠` 可以吃 `🐘 象`（鼠吞神象）；
2. **同级互吃**: 同级动物相遇，先下手者胜（先走者吃对方）；
3. **飞跃小河**: `🦁 狮` 和 `🐯 虎` 可以横向或纵向飞跃小河，但如果河道中有 `🐭 鼠` 阻挡，则无法飞跃；
4. **潜水能力**: 只有 `🐭 鼠` 能够进入小河游泳，陆地猛兽无法下水；水中的老鼠不能直接吃岸上的大象；
5. **胜负判定**: 任一方进入对方大本营（兽穴 🏰）即直接判胜，或吃光对方所有动物。
